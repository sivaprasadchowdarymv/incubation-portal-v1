# Submission Attempts
SAMPLE DOCUMENT. Each team has three formal submission attempts in total, including the first submission. A fourth submission is not permitted. An attempt is consumed once the file is formally recorded, even if it later fails validation. Uploads rejected before recording, such as a wrong file type or an oversized file, do not consume an attempt.

# Deadline
The Phase 1 submission deadline is 30 November 2026 at 23:59:59 India Standard Time (Asia/Kolkata). The deadline is enforced using the server clock. No submissions are accepted after the deadline.

# Resubmission
If a submission fails validation, the team receives a failure report with corrective guidance and may resubmit while attempts remain and the deadline has not passed. A new attempt cannot be made while an earlier submission is still pending review.
